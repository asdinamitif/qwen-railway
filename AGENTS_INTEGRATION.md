# Интеграция Агентов: Ruflo и Shannon

Это руководство описывает, как наделить АСЮ способностью запускать специализированные «рои» агентов для решения сложнейших задач.

## 1. Ruflo: Нервная система АСИ
Ruflo — это оркестратор, который позволяет одной модели управлять десятками специализированных помощников.

### Шаг 1: Установка Ruflo на компьютер
Убедитесь, что у вас установлен Node.js, затем выполните в терминале:
```bash
npx ruflo@latest init wizard
```
Следуйте инструкциям мастера настройки.

### Шаг 2: Регистрация Ruflo в OpenHuman (через MCP)
АСЯ взаимодействует с Ruflo через протокол MCP.
1. Откройте **OpenHuman**.
2. Перейдите в настройки (Settings) -> **MCP Servers**.
3. Нажмите **Add Server** и добавьте следующую команду запуска:
   - **Name**: `ruflo`
   - **Command**: `npx`
   - **Args**: `ruflo@latest mcp start`

Теперь АСЯ увидит инструменты Ruflo и сможет создавать агентов.

---

## 2. Shannon: Мастер Безопасности
Shannon — это автономный пентестер и аналитик безопасности. Мы добавим его как «навык» (skill) для Ruflo.

### Шаг 1: Установка навыка
В терминале вашего проекта (где инициализирован Ruflo) выполните:
```bash
npx skills add unicodeveloper/shannon
```

### Шаг 2: Синхронизация
Синхронизируйте навыки, чтобы они стали доступны агентам:
```bash
bash ~/.agents/skills/shannon/scripts/sync.sh
```

---

## 3. Как пользоваться (Команды для АСИ)
После настройки вы можете отдавать АСЕ команды прямо в чате OpenHuman:

- **Создание роя**: «АСЯ, запусти рой программистов для анализа этого репозитория».
- **Аудит безопасности**: «АСЯ, используй Shannon, чтобы проверить мой локальный сайт http://localhost:3000 на уязвимости».
- **Автономная работа**: «АСЯ, создай агента-исследователя, пусть он найдет всю информацию про [тема] и составит отчет».

### Как это работает:
1. Вы просите АСЮ выполнить сложную задачу.
2. АСЯ понимает, что ей нужны помощники, и через **Ruflo MCP** вызывает команду `swarm_init`.
3. Ruflo создает виртуальных агентов (Coder, Reviewer, Security), которые обмениваются сообщениями и выполняют работу.
4. АСЯ контролирует процесс и выдает вам финальный результат.

---
**Совет**: Если АСЯ говорит, что не знает, как запустить агентов — напомните ей заглянуть в её системный промт или проверить подключение MCP сервера `ruflo`.
