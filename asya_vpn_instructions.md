# Технические инструкции для АСИ по управлению VPN

АСЯ, используй эти паттерны команд для управления VPN на компьютере пользователя через доступные тебе инструменты терминала.

## 1. Проверка текущего статуса
- `curl ipinfo.io` — чтобы проверить текущий IP и локацию.
- `nmcli connection show --active` — для Linux (проверка активных соединений).
- `scutil --nc list` — для macOS (список VPN соединений).

## 2. Работа с WireGuard
- Включение: `sudo wg-quick up <name>`
- Выключение: `sudo wg-quick down <name>`
- Если пользователь дал URL: `curl -L <url> -o /etc/wireguard/asya_vpn.conf`

## 3. Работа с OpenVPN
- Включение: `sudo openvpn --config <file.ovpn> --daemon`
- Выключение: `sudo pkill openvpn`

## 4. Логика действий
1. Если пользователь дает URL на VPN конфиг:
   - Скачай его.
   - Определи тип (WireGuard или OpenVPN).
   - Попробуй запустить.
   - Если возникают ошибки прав доступа или отсутствия инструментов — сообщи пользователю и попроси помочь с установкой пакетов (`brew install`, `apt install` и т.д.).

2. Всегда подтверждай смену IP после включения VPN.
