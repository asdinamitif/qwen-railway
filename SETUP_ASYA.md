# SETUP ASYA: Полное руководство по установке

Это руководство поможет вам собрать **АСЮ** — вашего персонального ИИ-ассистента, объединяющего возможности OpenHuman, Ruflo и Shannon на базе модели Qwen 3.5.

## 1. Подготовка Бэкенда (Мозг)
Бэкенд уже настроен в этом репозитории для запуска на **Railway**.
- Разверните этот проект на Railway.
- Убедитесь, что подключен Volume на `/data`.
- В переменных окружения (Variables) можно задать:
  - `MODEL_URL` (по умолчанию Qwen 3.5 9B Uncensored Q6_K)
  - `MMPROJ_URL` (Vision-модуль для работы с картинками)

## 2. Автономное Приложение (Standalone GUI)
Теперь АСЯ может работать как самостоятельное приложение на вашем компьютере, не требуя сторонних оболочек.
- Установщик `install_asya.bat` создаст всё необходимое и запустит окно чата.
- **Преимущества**: Легкость, работа напрямую с вашим бэкендом, встроенная поддержка команд.

## 3. Альтернатива: OpenHuman
Если вы всё же хотите использовать OpenHuman (для памяти и маскота):
- **Скачайте**: [Релизы OpenHuman](https://github.com/tinyhumansai/openhuman/releases/latest)
- В настройках укажите адрес вашего Railway-сервиса.

## 3. Настройка Агентов (Ruflo и Shannon)
Чтобы АСЯ могла запускать специализированные команды помощников и проводить аудит безопасности:
- Ознакомьтесь с подробной инструкцией: **[AGENTS_INTEGRATION.md](AGENTS_INTEGRATION.md)**.
- Там описано, как подключить Ruflo через MCP и добавить навыки Shannon.

## 5. Голос и Управление (STT/TTS)
Для общения голосом рекомендуется:
- **STT (Слух)**: Использовать встроенный в OpenHuman Whisper.
- **TTS (Голос)**: В настройках OpenHuman выберите русский женский голос (через Piper или ElevenLabs).

## 6. Настройка VPN
АСЯ может управлять вашим VPN. Для этого:
- Передайте АСЕ URL вашего VPN-конфига или сам файл.
- Убедитесь, что на вашем компьютере установлены необходимые CLI-инструменты (например, `openvpn` или `wireguard-tools`).
- АСЯ будет использовать эти инструменты через терминал OpenHuman для включения/выключения соединения.

## 7. Десктопные инструменты (Deskreen и Flow Launcher)
Для максимальной продуктивности:
- **Flow Launcher**: Быстрый поиск файлов и запуск приложений. АСЯ может предлагать команды для него.
- **Deskreen**: Позволяет использовать планшет или телефон как второй монитор. АСЯ поможет настроить трансляцию.
- Эти инструменты устанавливаются автоматически при запуске `install_asya.bat`.

## 8. Анимированный Дизайн
АСЯ — это не просто текст. Это анимированный персонаж.
- В OpenHuman по умолчанию используется маскот.
- Вы можете настроить его внешний вид в **Settings -> Appearance**.
- АСЯ синхронизирует свою анимацию с ответами, создавая живой интерфейс.

## 9. Системный промт
Скопируйте содержимое файла `asya_system_prompt.txt` в настройки системного промта OpenHuman. Это задаст АСЕ её личность и характер.

## 8. Автоматическая настройка (Рекомендуется)
Вы можете настроить всё окружение (Ruflo, Shannon, agent-browser) одной командой.
1. Убедитесь, что у вас установлен **Python** и **Node.js**.
2. Скачайте файл `asya_auto_setup.py` из этого репозитория.
3. Запустите его:
   ```bash
   python asya_auto_setup.py
   ```
4. Скрипт сам установит нужные компоненты и попросит вас ввести URL бэкенда.
